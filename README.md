# Proyecto_Capstone_001D_InfoDuoc-Brandon-Vicente-Benjamin
Una aplicación web en Modo Kiosco para la sede San Joaquín. Orienta a alumnos, docentes y visitas mediante un mapa interactivo SVG de 8 pisos, directorio institucional, buscador con tolerancia a errores y soporte offline (PWA), resolviendo la desorientación en la búsqueda de salas y servicios.
