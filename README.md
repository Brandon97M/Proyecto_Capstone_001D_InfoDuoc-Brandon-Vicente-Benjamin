# Proyecto_Capstone_001D_InfoDuoc-Brandon-Vicente-Benjamin
## Descripción
* **Qué hace:** Aplicación web para tótem táctil con mapa SVG interactivo de 8 pisos, directorio y buscador con tolerancia a errores[cite: 2].
* **A quién va dirigido:** Alumnos de primer año, docentes nuevos, visitas y la comunidad académica de Duoc UC San Joaquín[cite: 2].
* **Qué problema resuelve:** Elimina la desorientación al ubicar salas, laboratorios y servicios dentro del edificio de 8 pisos[cite: 2].

## Tecnologías Utilizadas
* **Lenguajes:** JavaScript (ES6+), HTML5, CSS3, SQL.
* **Frameworks:** Node.js / Express (Backend), SPA PWA / Service Workers (Frontend)[cite: 2].
* **Base de Datos:** PostgreSQL / MySQL[cite: 2].
* **Cloud / Infraestructura:** Docker, Docker Compose.
